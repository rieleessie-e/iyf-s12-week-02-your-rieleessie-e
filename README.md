## Project Description
A responsive portfolio site that turns my Week 1 HTML into a styled,
mobile-first website using Flexbox, Grid, and CSS custom properties.

## Technologies Used
- HTML5
- CSS3 (Flexbox, Grid, Media Queries, Custom Properties)
- Google Fonts (Poppins + Open Sans)

## Features
- Responsive navigation bar
- Hero section with call-to-action button
- Project cards in a responsive 1/2/3 column grid
- Styled contact form with focus states
- Multi-column footer that stacks on mobile
- Box model practice page

## How to Run
1. Clone this repository
2. Open `index.html` in your browser

## Lessons Learned
I learned how the box model works, why `box-sizing: border-box` matters,
and how to build layouts that adapt from mobile to desktop using media queries.

## Challenges Faced
Getting the project grid to go from 1 to 2 to 3 columns took a few tries —
I had the media queries in the wrong order at first. Writing the base styles
first and then adding larger breakpoints fixed it.
